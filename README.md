# LS23 Transport

Website for LS23 Transport, the transport and logistics business of Soufyane El Haddar e.U. in Austria. The live site is [ls23transport.at](https://ls23transport.at)

## Tech

HTML, CSS, and JavaScript, with ESLint and Prettier. Hosted on Hostinger.

## Run locally

Open `index.html` in a browser. There is no build step.

ESLint and Prettier need dev dependencies:

```bash
npm install
npm run lint
npm run format
```
